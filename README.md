# IAI Mbalmayo - Institut Africain d'Informatique

Centre d'Excellence Technologique - Mbalmayo, Cameroun

![IAI Mbalmayo](https://picsum.photos/id/1015/800/400)

## 📋 Description du Projet

Site web officiel de l'Institut Africain d'Informatique - Centre de Mbalmayo, dédié à la formation d'excellence en technologies de l'information et de la communication. Le site présente nos formations en génie logiciel, intelligence artificielle, cybersécurité, data science et réseaux & télécommunications.

### 🎯 Objectifs
- Présenter l'institut et ses formations
- Faciliter les inscriptions en ligne
- Informer sur les actualités et événements
- Fournir un contact direct via WhatsApp
- Être entièrement responsive et moderne

## 📁 Structure du Projet

```
iai-mbalmayo-site/
│
├── index.html              # Page d'accueil
├── about.html              # À propos de l'institut
├── formations.html         # Présentation des formations
├── admissions.html         # Conditions et processus d'admission
├── postuler.html           # Formulaire de candidature
├── actualites.html         # Actualités et événements
├── contact.html            # Coordonnées et formulaire de contact
│
├── css/
│   └── style.css           # Styles personnalisés (optionnel)
│
├── js/
│   └── script.js           # JavaScript pour interactions
│
├── images/                 # Images et ressources médias
│
└── README.md              # Ce fichier
```

## 🚀 Technologies Utilisées

- **HTML5** - Structure sémantique
- **TailwindCSS** - Framework CSS utilitaire
- **JavaScript ES6** - Interactions et formulaires
- **Font Awesome** - Icônes
- **Google Fonts** - Typographie (Inter, Playfair Display)

## 💻 Comment Tester Localement

### Prérequis
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Connexion internet pour les CDN (TailwindCSS, Font Awesome)

### Lancement
1. Clonez ou téléchargez le projet
2. Ouvrez le dossier `iai-mbalmayo-site/`
3. Double-cliquez sur `index.html` pour ouvrir dans votre navigateur
4. Naviguez entre les pages via le menu

### Fonctionnalités à Tester
- ✅ Navigation responsive (menu mobile)
- ✅ Formulaire de candidature avec WhatsApp
- ✅ Smooth scrolling
- ✅ Animations au survol
- ✅ Bouton WhatsApp flottant

## 🌐 Déploiement en Ligne

### Netlify (Recommandé)
1. Créez un compte sur [Netlify](https://netlify.com)
2. Cliquez sur "Deploy manually"
3. Glissez-déposez le dossier `iai-mbalmayo-site/`
4. Votre site sera accessible à une URL comme `https://amazing-site.netlify.app`

### Vercel
1. Créez un compte sur [Vercel](https://vercel.com)
2. Importez votre projet GitHub ou déployez manuellement
3. Le déploiement se fait automatiquement

### GitHub Pages
1. Créez un repository GitHub
2. Uploadez tous les fichiers du projet
3. Allez dans Settings > Pages
4. Sélectionnez "main branch" comme source
5. Votre site sera accessible à `https://username.github.io/repository-name/`
